## 0. 现在要实现的内容

### 0.1 目标（北极星）
会话从「可变快照」改成「append-only 事件日志」；**持久化与可恢复**，四个场景全要：
① 崩溃后续跑未完成 turn ② 跨会话 resume ③ 审批挂起 ④ undo/redo 持久化。

### 0.2 已拍板（D1–D8）
| # | 决策 |
|---|---|
| D1 | **放弃 Java 兼容**（仓里无 Java 源） |
| D2 | 会话文件 = **独立 `<id>.jsonl`**（append-only），唯一真相源 |
| D3 | **消息加稳定 id**（创建时铸） |
| D4 | **只做持久化层**（不碰三域事件 / waterfall） |
| D5 | P2 后**彻底删除** `.json` 快照 |
| D6 | `acceptance`/`step_deliveries`/`harvest` **本轮事件化** |
| D7 | 变更→事件 = **显式发射**（session 变更方法），**否决** diff / setter |
| D8 | 压缩 = **融合**（dsh 括号+溯源 + OpenCode 的 replacement 列表 + 保留 4 层策略） |

### 0.3 根因（第一性原理）
**持久化是快照语义（只存"现在是什么"），四场景要的是日志语义（要存"发生过什么"）。** 修根源 = 引入日志。

## 5. 新增功能：每个文件怎么改，每一步

### 5.1 `domain/message.py`（改）
- **步 1**：`ChatMessage` 加 `id: str = ""`。
- **步 2**：`__post_init__` 末尾：`if not self.id: object.__setattr__(self, "id", uuid4().hex)`。
  - **为什么**：15 处构造点**零改动**即得 id；`from_dict` 传已存 id 则保留（回填自然发生）。
- **步 3**：`_message_to_dict`（在 `session.py`）非空才写 `id` 键；`_message_from_dict` 读 `id`（缺失 → `""` → `__post_init__` 回填）。

### 5.2 `domain/session_events.py`（新，纯，无 I/O）
事件词汇 + 折叠 + 修复。**每个事件附"为什么存在"**：

| type | payload | 为什么存在 |
|---|---|---|
| `session/created` | `{sessionId, title, createdTime}` | 头信息（第一行） |
| `turn/start` | `{turn}` | **崩溃检测唯一依据** |
| `turn/end` | `{turn, status, reason, usage?, handoff?, closing?}` | 关回合 + 账目（合并 usage，不设独立事件） |
| `message` | `ChatMessage.to_dict()`（含 id） | 消息历史 |
| `task` | `TaskState.to_dict() \| null` | 任务态整值替换（dsh 的 task 也是整值） |
| `digest` | `TurnDigest.to_dict()` | 回合摘要环 |
| `acceptance` | `[AcceptanceItem.to_dict()]` | 验收契约整值替换 |
| `delivery` | `StepDelivery.to_dict()` | plan 步收据 |
| `compact/start` | `{compactionId, turn, reason}` | **括号开**（孤儿压缩可检测，dsh） |
| `compact` | `{compactionId, shadowedIds, replacement, summary?, usage?}` | 压缩结果（dsh 溯源 + OpenCode replacement 列表） |
| `compact/end` | `{compactionId}` | **括号闭** |
| `harvest` | `{count}` | 记忆收割游标 |
| `approval/asked` | `{requestId, toolName, params, reason}` | 审批 durable |
| `approval/decided` | `{requestId, outcome}` | 审批结论 |
| `undo` | `{removedMessages, turnCount, digests}` | undo durable（携带被移除内容，redo 才有得恢复） |
| `redo` | `{restoredMessages, turnCount, digests}` | redo 的逆 |

**函数**（每个都说清作用）：
- `fold(events) -> SessionData`：按 seq 应用；`turn_count` 取 `turn/start` 的 turn 并被 undo/redo 覆盖；`messages` 追加，遇 `compact` 整值替换，遇 undo/redo 替换；`turn_usages` 从各 `turn/end.usage` 派生；`last_compacted_turn` 取最后一个 `compact.turn`；`last_access_time` 取最后一行 `time`。
- `is_turn_open(events) -> int | None`：最后一个无配对 `turn/end` 的 `turn/start`。
- `is_compaction_open(events) -> CompactionId | None`：同上，对 `compact/start`/`compact/end`。
- `repair(events) -> list[Event]`：为 open turn 合成 `turn/end{status:"interrupted"}`；为 open compaction 合成 `compact/end`。纯函数，不改原事件。

> **砍**：不设 `usage` 事件（合进 `turn/end`）；不设 `touch` 事件（`last_access_time` 派生）；不设 `diff`（D7 否决）。

### 5.3 `domain/session.py`（改）
- **步 1**：`SessionData.from_events(events)` → 调 `session_events.fold`。
- **步 2**：加**变更方法**（每个都写状态 + 记录待发事件到 `self._pending`）：

| 方法 | 替换的写入点 | 发的事件 |
|---|---|---|
| `append_message(msg)` | `add_message`（9 处） | `message` |
| `apply_compaction(new_list, shadowed_ids)` | compaction.py:334 `session.messages = list(result)` | `compact` |
| `begin_undo(removed, turn_count, digests)` | agent_loop:1474 及三字典 | `undo`（携带被移除内容） |
| `begin_redo(restored, turn_count, digests)` | agent_loop:1552 | `redo` |
| `set_task(task)` | `session.task = …`（agent_loop:746；`begin_plan`） | `task` |
| `bump_turn(turn)` | `session.turn_count = …+1`（agent_loop:743） | `turn/start` |
| `append_digest(d)` | `append_digest()`（turn_digest.py:225 的 ring 写） | `digest` |
| `set_acceptance(items)` | plan_runner:525 | `acceptance` |
| `set_deliveries(list)` / `append_delivery(d)` | plan_runner:333/376/569 | `delivery` |
| `set_harvested(n)` | memory_turn:180 | `harvest` |

| `drain_pending()` | — | 返回并清空 `_pending` |

- **步 3**：加**非持久化**字段 `_pending: list[dict]`（`to_dict` 白名单不含）；`interrupted_turn: int|None`、`pending_approval: dict|None`（内存态）。

> **砍**：不新增 `set_compaction_turn`（从 `compact.turn` 派生）；不新增 `record_usage`（已存在，改为从 `turn/end` 折叠时填）。

### 5.4 `service/session_service.py`（原地重构，签名不变）
- **步 1**：`create` → 写 `session/created` 首行。
- **步 2**：`save(session)` → `append(session.drain_pending())`（原子追加，一行一事件，`os.replace` 不再需要整文件）。
- **步 3**：`load(id)` → 读全部行 → `repair` → `fold` → `SessionData`；若 repair 补了事件，**追加**它们（原事件不改）。
- **步 4**：`list_sessions` → 读**首行**（头）+ **末行**（last_access）+ 行数（≈ message 数）。
- **步 5**：迁移：`load` 遇 `.json` 无 `.jsonl` → 读 old JSON → 逐字段 emit 事件写 `.jsonl` → 删 `.json`。

### 5.5 `core/turn_close.py`（改内部）
- `save(session)`：`self._sessions.save(session)`（内部已变 drain+append）。`checkpoint`/`finalize`/`close` 签名不变。
- **删**：`ensure_tool_pairing` 的"落盘前可变清理"降级为**折叠时校验**（日志是 append-only，不应在写前改历史）。

### 5.6 `core/agent_loop.py`（改写入点）
- `_begin_turn`：`session.turn_count += 1` → `session.bump_turn(turn)`；`session.add_message` → `append_message`。
- `session.task = …` / `session.continuations`（保持 in-process）/ user/assistant/nudge/steering 的 `add_message` → `append_message`。
- undo/redo：三个内存字典（`_undo_tail`/`_undo_state`/`_undo_files`）**删**；改为 `session.begin_undo(...)`（发 `undo` 事件，携带 removedMessages/turnCount/digests），redo 同理；文件半边仍走 `SnapshotStore`。

### 5.7 `core/compaction.py` + `core/context_compression.py`
- `compact_now`：`session.messages = list(result)` → `session.replace_messages(list(result), shadowed_ids)`；外层加 `compact/start`…`compact/end` 括号（发事件）。
- `compress()` / 4 层 / `sanitize_pairs`：**不改**。
- **砍**：不重写为 range ops（D8）。

### 5.8 `core/dispatch.py` + `security/approval.py`
- `dispatch` 在调用审批回调前发 `approval/asked`；拿到结果后发 `approval/decided`（携带 `ApprovalResult.value`）。
- **`approval.py` 不改**（协议/枚举复用）。

### 5.9 `core/plan_runner.py` / `core/memory_turn.py`
- `session.step_deliveries = / .append(...)` → `set_deliveries`/`append_delivery`；`step_session.acceptance = …` → `set_acceptance`；`session.harvested_messages = …` → `set_harvested`。

### 5.10 `server/handlers.py`
- `session.prompt`：load 后若 `session.interrupted_turn` 非空 → 前端提示"上次回合未完成"；若 `pending_approval` 非空 → 重发 `approval.request`。

## 6. 对数据流的影响

```
改前: AgentLoop 写 SessionData → TurnCloser.save → to_dict 整文件 → os.replace
改后: AgentLoop 用 session 变更方法写 SessionData（同时记录 _pending 事件）
      → TurnCloser.save → SessionService.save = append(drain_pending())
      读: load → repair → fold → SessionData
      崩溃: is_turn_open → repair 合成 turn/end{interrupted}
```
- **写路径**：多一层"变更方法 → _pending → append"；对外签名不变。
- **读路径**：多一层"repair + fold"；对外签名不变。
- **内存**：`SessionData` 仍是唯一内存模型，读点全不改。

## 7. 修改成功后的效果

1. **崩溃续跑**：kill -9 后重启，load 报 turn N 未完成，可续跑。
2. **resume**：只留 `.jsonl` 也正确 load；消息带稳定 id。
3. **审批挂起**：日志有 `approval/asked`+`/decided`；重启可见 `pending_approval`。
4. **undo/redo 持久化**：重启后 `/redo` 可用。
5. **对账**：`fold(log) == 内存 session`。
6. **压缩可审计**：`compact/start`…`compact/end` 括号 + `shadowedIds` 溯源。
7. **transcript 不丢**：原始 `message` 事件不被删除。

## 9. 架构图

```
┌───────────────────────────────────────────────────────────────┐
│ AgentLoop / TurnCloser / plan_runner / memory_turn  (写入方)   │
│   调 session 变更方法 (append_message/replace_messages/…)      │
└───────────────┬───────────────────────────────────────────────┘
                │ 方法内：改 state + 记 _pending 事件
┌───────────────▼───────────────────────────────────────────────┐
│ domain/session.py   SessionData（折叠产物 + 变更方法 + _pending）│
│ domain/session_events.py  事件词汇 + fold + repair（纯）        │
└───────────────┬───────────────────────────────────────────────┘
                │ save() → drain_pending()
┌───────────────▼───────────────────────────────────────────────┐
│ service/session_service.py（重构）                              │
│   save=append(原子追加)  load=read→repair→fold                  │
│   list=读首行+末行       迁移=老 .json → .jsonl → 删 .json       │
└───────────────┬───────────────────────────────────────────────┘
        sessions/<id>.jsonl   ← 唯一真相源（append-only）

崩溃: turn/start(open) → repair 合成 turn/end{interrupted}
压缩: compact/start → compact{shadowedIds,replacement} → compact/end
审批: approval/asked → approval/decided
undo: undo{removed…} → redo{restored…}
```
