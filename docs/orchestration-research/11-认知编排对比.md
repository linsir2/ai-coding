## 0. 裁决：三家都"先想 → 列 todo → 再干"吗？

**不是。"todo 主干"是我们独有的；dsh 把 todo 当 UI 进度条；opencode 已删除该工具。**

| 事实 | 我们 | dsh | opencode |
|---|---|---|---|
| 工具 | `todo_write`；描述写死了职责："**This list is your plan** … the run is not considered finished while items are still open"（`tools/todo_write_tool.py:37-48`）；另有 evidence / verify / 依赖检查三件套（`:46-47,76-83,123-153`） | `todo_write`；描述要求"开工前把每个具体步骤列出来"（`tool-todo/src/index.ts:45-47`）；三态，无 evidence/verify/依赖 | **无**：v1→v2 移除（`v1-migration.bun.ts:901`），迁移测试断言 "no longer available and must not be called"（`v1-migration.test.ts:508`） |
| 状态去向 | 任务状态**每迭代注入请求**（`request_assembly.py:170,263`） | "**Log-only UI state; never derived history**"（`tool-todo/src/types.ts:30`）；下个 `turn/start` 清空（`index.ts:127-131`） | — |
| 写了之后 | 未完成项 → 持久 `[task-gate]` nudge 推动（预算 2 次，`turn_policy.py:45-46,308-320`） | **零影响**：不进请求、不推动、不跨回合 | — |

一句话：我们把 todo 做成认知主干（状态每迭代注入＋门持续推动＋证据纪律）；dsh 是"进度条＋开工清单"（显式规划期还禁用，见附录 §6）；oc 没有这个物种。

## 1. 三家认知数据流（各一条，普通回合）

### dsh：透明思考 + 环境事实 + 模式分流

```
输入 → durable inbox（落日志）→ turn/step 循环
  preStep   runtime-context 快照（cwd/沙箱/审批；变了才注入）/ skill / AGENTS.md / 时间…（08 §6A，8 类）
  build     identity + persona + 工具方法论 sections + 日志派生历史（08 §3）
  模型       reasoning 一等块：落日志（逐帧）→ Think 行 → 带签名回喂下次请求（08 §1）
  判        机制：还有工具→继续；不调工具 = 完成（agent.ts:547-550）
  应答       无收尾话术；UI 用"最后一条非空 text"；截断 = 诚实提示（08 §5）
```

中途输入 = queue/steer（`07`）；显式规划/长任务机制见附录 §6。

### opencode：隐式思考 + 指令基线 + 模式分流

```
输入 → inbox(SQLite) + doorbell → drain/step 循环
  build     system.txt 15 行 + instructions 基线（缓存友好序）+ 工具指引（09 §3.1-3.2）
  模型       reasoning 事件：delta 不落库、默认隐藏；End 落权威全文（09 §1.2）
  判        机制：needsContinuation = 这步调过本地工具吗（09 §5）
  异常       断流→合成续写消息；max-steps→"禁工具+逼总结"提示；length 截断 = 终（09 §2）
```

无 todo / goal（`07`）；显式规划机制见附录 §6。

### 我们：todo 主干 + 门 + 策略

```
输入 → IPC → _run_turn
  build     压缩 → 指令 → 注入 → 10 块 tail（声明序，request_assembly.py:259-272）
  模型       reasoning 捕获 → Thought 行 → 落库（不回喂）（10 §1）
  判        policy 唯一决策点：FINISH / NUDGE（task/strategy/fatigue/acceptance 等门）/ CONTINUE（turn_policy.py:308-320）
  应答       最后 text / C3 续跑 / _ask_for_closing / render_handoff（10 §6）
```

## 3. 关键分野（四条）

1. **todo 与"持续推动"**：我们独有（主干+门）；两家没有对应物——dsh 的重复调用提醒（第 3/5/8 次）是唯一近似，且只提醒永不否决。
2. **思考的利用深度**：dsh 全链（展示+回喂+降级）；oc 存且同端回放；我们单向下行——对 DeepSeek 语义正确，对签名类 provider 是未开发面。
3. **约束落地三态（普通回合同样成立）**：dsh 偏提示词＋环境事实（bash 的 exit-code 纪律、runtime-context 快照，都是"说给你听"）；oc 靠权限系统（工具级硬闸）；我们最机械（policy 门、acceptance 判定、预算）。三种答案对应三种可测性。
4. **干预密度**：我们最密（6 门常驻 nudge）；dsh 中等且多为 advisory（重复调用提醒只提醒不否决）；oc 最少（普通回合几乎零干预，synthetic 以机制性为主）。

## 6. 附录：显式规划机制对照（`/plan` ↔ plan mode ↔ Plan agent）——非主线，产品参考

> 触发条件是 `/plan` 命令或切换 agent（进入门见 `07`）；**普通回合不受其影响**。保留作产品对照（审批闸/强制机制/执行衔接的设计参考）；不需要可直接删本节。

| 维度 | 我们 `/plan` | dsh plan 模式 | oc Plan agent |
|---|---|---|---|
| 形态 | 同一会话的两阶段工作流（规划回合→逐步执行） | 会话级模式（日志+投影，**resume/fork 恢复**，`plan-mode/index.ts:9-13`） | 独立 agent（"Plan"，primary，`plan.ts:33-43`） |
| 进入 | `/plan [topic]` | `/plan [message]`：回合内排队、回合外即生效+narration（`:196-213,425-445`；narration `:462-474`） | 用户切 agent（事件→注入提醒，`:76-97`） |
| 规划期约束 | 提示词（`PLAN_PROMPT`，`plan_runner.py:58-67`）+ **C3 续跑关闭**（`:139-141`） | 提示词 section 每请求注入（order 500，`:216-224`）；**工具目录不变（为请求缓存稳定）**（`:62-66`） | **权限硬闸**：edit 全拒、仅 `~/.opencode/plan` 可写（`plan.ts:38-41`）；阻断后改写错误文案（`:45-54`） |
| 产物 | **可执行 todo（每步带 verify 命令）** | 完整 markdown 计划（必须以 `#` 开头，`:304-306`） | 对话中的方案（可写 plan 目录文件） |
| 审批闸 | 无（规划完直接跑） | **有**：`exit_plan_mode` → Approve / Keep planning 弹窗（`:313-330`）；驳回 = **工具报错带反馈重提**（`:349-354`）；dismiss = 回合结束（`:331-341`） | 无（用户自己切回 agent 执行） |
| 执行衔接 | PlanRunner：依赖序、**每步一个 bounded 回合**（实测省 30% token）、step head"只做这一步"（`:8-20,44`）；机械判定：proof 失败 = blocked（即使模型说完成）、无 proof 未完 = stalled、每步一次修理后停 | 批准文案 "carry out the plan starting with your next step"（`:291-296`）；模型自然继续 | 切回默认 agent，正常循环 |
| 跨压缩 | receipts 重放（`:5-6`） | plan/mode 投影恢复 | 每请求对账补提醒（`:56-74`，压缩剥掉会重插） |

**本质差异在"强制机制"**：dsh = **纯提示词**（为缓存故意不换工具目录）；oc = **权限系统**（真拒，但只挡不引导）；我们 = **机械**（verify 命令、blocked/stalled 判定、per-step policy、预算）。

附：dsh 审批闸的三出口写死了"规划期的对话不算数"——"A user's conversational agreement … approves nothing and does not end plan mode"（`base/cordis.patch.yml:336`）。
